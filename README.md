# 🟨 THE BACKROOMS: LEVEL 0 // 神人最新力作

一个基于 **Three.js** 开发的沉浸式第一人称 3D 恐怖逃生网页小游戏。
关卡参考 [Backrooms Wiki 的 Level 0「The Lobby」](https://backrooms.fandom.com/wiki/Level_0)：旧零售场所后场般的泛黄房间、不重复的分隔格局、受潮地毯、散落的墙面插座，以及分布不均的荧光灯。游戏另加入了门框式开口、成片空房和一间仅有昏橙色灯光的马尼拉休息室；进入休息室可缓慢恢复理智与体力。大量 Smiler 是本游戏应玩家要求加入的玩法改编，并非该页面声称的 Level 0 原设定。

10. **Web Audio 动态音频系统**：
    - **60Hz/120Hz 荧光灯镇流器电流嗡鸣**与突发闪烁杂音
    - **潮湿地毯脚步声**（行走/疾跑双频拟真）
    - **理智过低心跳声**（双心室咚咚律动）
    - **提供的循环叫声**按实体与玩家的距离平滑衰减
    - **物品拾取清脆合成和弦**
    - **跃迁卡入突发惊吓冲击音**

游戏里有 20 个分散巡逻的 Smiler，会沿迷宫通道追击玩家。WebGL 默认绘制上限为 45 FPS，可在游戏里选择其他帧率；荧光灯只为玩家附近最近的 8 个灯位创建点光源。重复的墙体、柱体、门框、灯板、墙脚线、插座、弹药和储物柜使用实例化绘制，减少绘制调用。

迷宫里还有箱堆、铁柜和油桶等实体障碍物，以及地毯污渍、墙面水痕与散落碎屑。矮障碍可以跳过，高柜需要绕行；障碍物也会阻挡移动和相应高度的射线。独立窗口在鼠标锁定失败或失去焦点时会暂停，点击“继续探索”可重新锁定。

## 🕹️ 游戏玩法与操作指南

### 核心目标
1. 迷宫中散落着 **3 枚门禁芯片 (Keycard)**，深入回廊将它们全部收集。
2. 随时关注 **精神值 (Sanity)**，在黑暗中待太久或离实体太近会导致理智崩溃。
3. 收集 **杏仁水 (Almond Water)**，按 `G` 饮用可大量恢复理智与体力。
4. 拾取 **9V 电池 (Battery)** 确保手电筒不熄灭。
5. 避开游荡的**微笑者实体 (The Smiler)**！它会沿走廊追击；被逼近时可以探头观察路线，或按 `G` 躲进储物柜，等它搜索离开。
6. 收集地面的 **记忆微光** 恢复理智和体力；在湿滑积水前跳跃通过。
7. 找到手枪与弹药箱，击倒 Smiler 可以争取喘息；但枪声会引来附近实体，它会在 12 秒后从远处复活。
   地图另有两把 M7；M7 命中 10 发、手枪命中 3 发、AWM 命中 1 发可击倒一个 Smiler。
8. 凑齐 3 枚芯片后，前往地图深处的 **安全出口 (EXIT)**，按 `G` 完成“卡出 (No-Clip)”脱离后室！

### 按键操作
| 按键 | 功能 |
| :--- | :--- |
| **W / A / S / D** | 前后左右移动 |
| **鼠标滑动** | 360° 旋转视角（第一人称视角） |
| **按住 Q / E** | 左 / 右探头，松开复位 |
| **鼠标左键** | 点击锁定鼠标视角 / 开始游戏 |
| **Shift** | 起跑；松开 Shift 后继续冲刺，松开方向键或体力耗尽时停止 |
| **V / Ctrl** | 蹲下；奔跑时按下发起消耗体力的滑铲，滑动时转动鼠标或按方向键可改变方向 |
| **Space** | 低跳；滑铲中或结束后短时间内按 Space 可衔接滑铲跳并保留前冲惯性 |
| **1 / 2 / 3 / 4 / 5** | 切换空手、手枪、杏仁水、AWM、M7 |
| **鼠标左键** | 射击 / 使用杏仁水；M7 按住左键可连射 |
| **R / 鼠标右键** | M7 按 R 换弹并做取放弹匣动作；手枪和 AWM 按 R 切换瞄准；右键按住瞄准，M7 使用红点瞄具 |
| **F** | 开关手电筒（暗处提供照明，消耗电池） |
| **G** | 拾取道具 / 靠近储物柜躲藏或离开 / 饮用杏仁水 / 打开安全门 |
| **M** | 展开/折叠右下角雷达小地图 |
| **I** | 打开作弊轮盘，可单独勾选透视、无限体力、无限弹药、无敌、穿墙、飞行和加速 |
| **K** | 切换 Smiler 透视、无限体力与无限子弹；开启时获得手枪、AWM 和 M7，并自动装备手枪 |
| **L** | 无敌、穿墙、飞行与极速；飞行时 `Space` 上升、`V` 或 `Ctrl` 下降 |
| **ESC** | 暂停游戏 / 释放鼠标指针 |

开始界面和暂停界面可以调 Smiler 叫声音量、选择 30～120 FPS 帧率上限，并试听两段“饿啊”死亡音效；设置会保存在本机。默认开启的“舒适画面”会去除镜头走路起伏、扫描线与枪口屏幕闪光，减轻探头倾斜，并稳定荧光灯亮度。死亡画面会显示小黄脸，死亡叫声逐次轮换播放。失焦或暂停时，持续环境声会停止。

## 🚀 启动与游玩方式

### 方式一：一键双击启动（推荐）
直接双击根目录下的 **`start_game.bat`**，游戏会在自己的 WebView2 窗口中运行，不会打开 Chrome 或 Edge 浏览器。首次启动会在项目的 `.venv` 中安装窗口组件；需要 Python 和 Windows WebView2 Runtime。

### 方式二：Python 命令行启动
在当前目录下运行：
```bash
python start_game.py
```
请先运行 `python -m pip install -r requirements.txt`；命令随后会打开游戏独立窗口。关闭窗口后本地服务也会退出。

### 方式三：直接打开
由于所有美术材质均已打包内嵌于 `assets/assets_bundle.js`，你也可以直接双击 **`index.html`** 在任意现代浏览器（Chrome、Edge、Firefox 等）中即开即玩！
